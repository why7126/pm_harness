# TilesFST UI 设计指南

## 目的

本文档是 TilesFST 设计方案的人读版 UI/UE 指南。它适用于新项目初始化、已有后台系统重构，以及判断 TilesFST 视觉语言是否适合某个产品。

机器可读的 Token 和组件规则请使用 `design.json`。导航专项实现规则请使用 `navigation.json`。需要快速查看视觉效果时，打开 `demo.html` 和 `navigation-demo.html`。

## 设计定位

TilesFST 不是通用蓝白后台界面。它的产品语言是：

- 工业石材质感
- 暗色旗舰界面
- 品牌金强调
- 紧凑的 B2B 数据运营
- 近直角、精确感控件

界面应呈现克制、高级、偏运营工具的感受。它适合瓷砖、石材、建材、展厅、目录、B2B 商贸和后台管理类产品，尤其适合强调材质、品质和库存结构的场景。

## 核心视觉规则

复用该方案时，应保留以下规则：

- 使用 `#18160F` 作为主页面背景。
- 使用 `#211E16` 和 `#100F0A` 表达表面层和深色面板。
- 使用 `#EDE8DF` 作为主文字色，次级文字使用其透明度变体。
- 使用 `#C8A055` 作为品牌金，用于 active、primary 和 selected 状态。
- `#E07050` 仅用于 hot、warning、destructive 或 error 强调。
- 保持近直角圆角：徽标 `1px`，控件 `2px`，卡片 `3px`。
- 优先使用细微边框，不依赖厚重阴影。
- 避免通用 SaaS 大圆角卡片、蓝色后台色盘和明亮发光效果。

## 字体

该方案在运营界面中使用系统无衬线字体，在品牌表达中使用克制的衬线品牌字体。

- 正文：`13px`，行高约 `1.8`。
- 侧边栏用户名称：`12px`。
- 侧边栏用户邮箱：`11px`。
- 分组标签：大写、弱化颜色，字距 `0.12em`。
- 品牌标题：衬线字体、品牌金，字距 `0.16em`。
- 页面标题：约 `22px`。
- Hero 或登录页品牌标题：可到 `38px` 至 `42px`。

谨慎使用大字号。这是偏运营的后台和目录型体验，视觉层级应主要来自密度、分组、边框和克制的对比，而不是过大的标题。

## 布局

Web 后台外壳使用固定侧边导航和可滚动主内容区。

- 侧边栏展开宽度：`264px`。
- 侧边栏收起宽度：`72px`。
- 侧边栏位置：sticky，`100vh`。
- 主内容内边距：`24px 24px 48px`。
- 内容最大宽度：`min(1440px, 100%)`。
- 卡片和表格应对齐到紧凑的后台仪表盘网格。

小程序体验是独立导航资产，包含自定义顶部导航和五项自定义 tabbar。不要把 Web 后台导航和小程序导航合并成一个通用模式。

## 导航

侧边栏是核心可复用资产，应作为完整交互模式保留。

- 收起状态通过 `localStorage` key `admin-sidebar-collapsed` 持久化。
- 展开状态显示品牌文案、版本号徽标、分组标题、导航标签、主题切换器和用户菜单。
- 收起状态仅显示 Logo、导航图标、展开按钮、主题图标和头像。
- active 导航项使用品牌金文字、轻微金色背景，并在左侧显示 `2px` 金色指示条。
- 员工角色会隐藏仅管理员可见的系统项：用户、设置、日志和接口文档。

侧边栏展开/收起按钮是一个 `28px` 图标按钮：

- 展开状态图标：`‹`
- 收起状态图标：`›`
- 展开状态 aria label：`收起侧边栏`
- 收起状态 aria label：`展开侧边栏`

版本号徽标位于品牌标题行：

- 高度：`18px`
- 内边距：`2px 7px`
- 圆角：`2px`
- 字号：`10px`
- 侧边栏收起时隐藏

## 用户菜单

侧边栏用户菜单应与真实 TilesFST 实现保持一致。

- 触发区结构：头像、显示名称、邮箱、chevron。
- 显示名称字号：`12px`。
- 邮箱字号：`11px`。
- Chevron 字符：`⌃`。
- Chevron 默认变换：`rotate(180deg)`。
- Chevron 展开变换：`rotate(0deg)`。
- Chevron 过渡：`transform 0.18s ease`。
- 侧边栏收起时：只显示头像，隐藏名称、邮箱和 chevron。

除非真实项目组件先发生变化，否则不要把该 chevron 替换成通用图标。

## 组件

使用紧凑、工业化的组件风格：

- 按钮：近直角圆角、品牌金 primary、透明 outline 和 ghost 变体。
- 输入框：紧凑态 `52px`，登录态 `64px`，focus 时使用品牌金边框。
- 卡片：半透明暗色表面、细微边框、`3px` 圆角。
- 徽标：`1px` 至 `2px` 圆角，偏大写或紧凑标签感，低调对比。
- 表格：弱化表头、细分隔线、轻微 hover 背景。

空状态、加载状态和错误状态应优先在局部字段或列表中反馈，不要一开始就依赖全局消息。

## 复用检查清单

在新项目中应用该方案前，确认：

- 产品可以承载暗色工业旗舰风格。
- 品牌可以接受金色作为主强调色。
- 后台工作流适合紧凑、便于扫描的信息密度。
- 侧边栏收起和版本号展示是目标项目需要的能力。
- 用户菜单 chevron 和字号与本指南一致。
- 如果使用小程序导航，应作为独立资产实现。
