# Git 交付安全

## 扫描范围

`python scripts/git-check.py` 读取 index blob，并独立检查受跟踪工作区。文件名以 NUL 分隔，冲突 index、符号链接/子模块、读取失败及扫描期间 index 变化阻断。工作区删除不取消 index 检查。检查后到提交前须复核 index；HEAD 变化须重跑历史检查。

`--all` 增加未忽略的未跟踪文件，不读取被忽略且未跟踪的真实 env，不代表历史扫描。`--base` 接收已核对的远端提交，检查 base..HEAD 每个提交树和提交消息；`--history` 用于首次推送。中间提交后删除的敏感内容仍阻断。浅克隆或对象缺失不能宣称完整历史检查通过。

文本限 UTF-8、1 MiB，超限与解码失败显式阻断。二进制内容不检查，仅检查路径和大小；超过读取上限的 Git 对象阻断。LFS 内容、子模块、标签注释和范围外引用需独立审查。正则启发式无法证明不存在任何秘密，成功仅表示声明范围内未命中。

## 脱敏与精确例外

报告仅包含来源、规则、行号、相对路径和数量，不包含命中行、部分凭证或原始 Git stderr。疑似敏感文件名及控制字符使用路径摘要标识。

占位符完整匹配固定示例值、尖括号标识或单个环境变量引用、全大写花括号模板参数或安全占位符默认值；额外示例值仅使用固定名单，不因含 example、localhost、change-me 或问号放行。数据库 URL 仅在用户名和密码均为完整占位符且无查询/fragment 时豁免；示例主机不能豁免真实凭证。路径规则识别具体用户名，正则分支语法不误报，不跳过整行或测试目录。

## 忽略与本地数据

`python scripts/validate-env-ignore-policy.py` 双向校验真实 env 忽略、示例可跟踪，并检查 index 中真实 env。使用 --no-index 检查规则，不读取真实 env。通用矩阵覆盖根目录、deploy 和 scripts，项目可按精确范围扩展。

Git ignore 不移除已跟踪文件。索引与历史风险分别处理；授权前不移出索引、不删除本地数据、不改写历史。运行数据、依赖与构建产物不得提交，模板占位文档按用途评估，不批量忽略长期证据。

## 告警复核

error 阻断；warning 提交前逐项记录来源、规则、位置、判断与依据。测试样例不因目录免检。哈希数字误报以精确边界及回归处理，不豁免证据目录。真实隐私需整改后复验。

## 同步与验证

授权的 /git-sync 按交付范围暂存、检查、提交、检查历史、快进推送并核对远端。保护已有 staged 内容；分叉按项目策略整合验证，不强制推送或覆盖 tag。正式 annotated tag 需发布事实和用户授权，注释单独检查。

回归：`PYTHONDONTWRITEBYTECODE=1 python scripts/test_git_check.py`，仅操作临时仓库，覆盖 index/worktree 分离、历史删除、占位符、脱敏、env、特殊路径、链接和覆盖不足。学习对象不执行测试或 Git 写入。
