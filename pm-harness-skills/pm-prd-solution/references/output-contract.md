# 输出契约

正式方案基线使用 `assets/baseline-templates/` 的完整目录，不得删除空缺章节掩盖未决问题；无内容时明确写“不适用”及理由。

## 正式交付条件

- 全部模板文件存在且非空
- 总览标明模式、版本、状态和输入来源
- 关键实体使用统一编号并能双向追踪
- 所有关键决策能追溯到用户确认或上游基线
- 未决项区分阻断与非阻断
- Patch 包含修改区、保护区、直接影响、连带影响和回归结论
- 不包含页面布局、字段清单、组件规格、视觉或技术实现

## 交付状态

- `草案`：允许存在阻断项，不得宣称已收敛
- `待确认`：主体完整，等待用户冻结关键结论
- `已冻结`：用户已明确确认且无阻断项
- `Patch 已冻结`：局部变更与影响范围已确认

运行 `validate_solution_baseline.py` 后才能交付正式基线。只有用户明确要求 ZIP 时才运行 `package_solution_baseline.py`。
