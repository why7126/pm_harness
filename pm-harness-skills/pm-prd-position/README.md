# pm-prd-position

产品定位 Skill v1.0。支持首次定位、重新定位和定位 Patch。

核心链路：
`Idea / Existing Positioning → pm-prd-position → Positioning Baseline → pm-prd-plan`

## 典型调用
- `@pm prd position 帮我完成这个产品的产品定位：……`
- `@pm prd position 重新定位，现有定位是……，目前问题是……`
- `@pm prd position patch 基于现有产品定位，仅调整目标客户……`

详见 `SKILL.md`。
