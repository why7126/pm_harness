# 验收与验证框架

## 两套标准

- 交付验收：判断功能、流程、异常恢复、非功能底线和业务闭环是否可用。
- 假设验证：判断目标用户是否获得核心价值，行为与业务指标是否达到预设阈值。

每项假设记录验证对象、方法、指标定义、阈值、数据来源、观察周期及继续/调整/停止标准。

## 数据闭环

记录关键行为、业务结果、指标口径、埋点或业务记录方式、数据源、分析周期、责任建议和数据质量校验，确保可采集、可解释、可追溯。

## 样本与上线

- 样本：目标特征、招募渠道、规模依据、代表性、排除条件、激励方式。
- 范围：按风险选择内测、定向试点或分阶段灰度。
- 控制：明确准入、观察周期、扩大、暂停与回退条件。

## 决策

未达阈值时记录失败假设、原因、影响范围、调整方案和下一轮退出标准；基于证据选择继续、调整或停止，不得默认扩充功能。每轮结束更新假设、范围、版本、风险与验证计划，并经用户确认生成新版基线。
