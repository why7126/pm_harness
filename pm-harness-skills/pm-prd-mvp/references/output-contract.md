# 输出契约与质量门禁

使用 `assets/baseline-templates/` 的全部 17 个 Markdown 文件。不得合并或遗漏。所有占位标记必须替换；不适用内容说明原因。

## 质量门禁

- 完整性：文件齐全，核心章节有实质内容。
- 一致性：用户、场景、闭环、范围、版本和指标无冲突。
- 可追踪性：关键对象有唯一编号和双向关联。
- 闭环成立性：目标用户可端到端获得价值并留下证据。
- 范围合理性：四层归属、理由、条件与复评节点明确。
- 指标可验证性：口径、阈值、来源、周期和决策标准完整。
- 依赖就绪度与风险可控性：责任、时点、验证和替代明确。
- 交接可执行性：设计边界、验收标准、约束和待设计问题清楚，且无页面/字段/交互越界。

存在阻断问题不得冻结或交付。校验通过后再生成与目录同名 ZIP。
