# 追踪与版本

## 编号

使用 `HYP` 假设、`LOOP` 闭环、`TASK` 用户任务、`FEAT` 功能、`VER` 递进版本、`MET` 指标、`DEP` 依赖、`RSK` 风险、`DEC` 决策。编号格式为 `类型-三位序号`。

追踪链必须双向覆盖：`定位结论 → 规划决策 → MVP 假设 → 业务闭环 → 功能/版本 → 验证指标`。任何必须纳入功能都应能追溯到闭环或底线；任何核心假设都应能追溯到指标。

## 语义化版本

- 首次冻结：`v1.0.0`。
- Patch：递增修订号。
- 重新收敛：兼容性扩展递增次版本；目标用户、核心价值、核心闭环或根本验证策略变化递增主版本。

每次变更记录来源、原因、修改项、锁定项、直接/连带影响、追踪关系变化、风险、迁移建议和用户确认。
