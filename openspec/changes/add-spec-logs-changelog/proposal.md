# add-spec-logs-changelog

## 背景

`docs/spec-logs/` 已经用于记录 ProjectPmHarness 的规范学习和治理迭代日志，但缺少一个总览文档来追踪每一次规范、脚本、命令和模板能力更新。

## 目标

新增 `docs/spec-logs/CHANGELOG.md`，作为规范工程变更历史索引，记录每次治理更新的时间、类型、摘要、影响范围、关联日志、关联 Change 和验证结果。

## 非目标

- 不替代单次 `study` 或 `governance` 详细日志。
- 不记录业务源码变更历史。
- 不同步到 `pm-harness/` 模板目录或 init-skill 模板资产。
