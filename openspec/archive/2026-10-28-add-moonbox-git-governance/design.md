## Context

复核发现原扫描器使用工作区内容和整行安全片段豁免，输出原始命中行。MoonBox 的逐项替换仍可能泄露同一行其他值，且子串占位符过宽。

## Goals / Non-Goals

目标：检查真实待提交快照、待推送历史和当前受跟踪工作区，报告不包含内容。非目标：凭证轮换、历史重写、自动提交推送或业务实现。

## Decisions

- Git 使用 NUL 分隔列表和对象 ID 读取 index blob，独立检查受跟踪工作区；不以工作区覆盖 index 检查。
- --base 检查 base..HEAD 全部提交树的唯一 blob/路径组合及提交消息，包含中间提交已删除内容；首次推送使用 --history 扫描 HEAD 可达历史。标签消息另由 git-sync 人工复核。
- --all 仅增加未忽略的未跟踪文件，防止读取本地真实 env；显式输出覆盖边界。忽略状态不能豁免已跟踪内容。
- 不输出行片段或 Git stderr；路径含疑似隐私时用摘要标识。占位符必须完整匹配，数据库 URL 单独核验凭证，不以 host/查询字符串豁免。
- 大文本或不可读对象显式阻断，二进制只做路径/大小检查；不宣称检测所有秘密。
- env 使用 Git check-ignore --no-index 检查规则，同时检查 index 中真实 env；路径矩阵为通用示例而非 MoonBox 业务配置。
- 技能只定义授权范围内的同步流程；保护既有暂存内容，禁止强制推送和移动既有 tag。

## Risks / Trade-offs

全历史扫描耗时较高，按对象与路径去重；启发式检查可能产生误报，保留逐项复核而非整目录豁免。模板例子与测试以运行时合成敏感样本避免误报。源资产和生成模板同步，历史报告不进入模板。
